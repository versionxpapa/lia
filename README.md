# LIA Voice Keyboard — decompiled resources

Apktool-decompiled output of the **LIA Voice Keyboard** Android app
(package `com.Lia.assistant`).

Contents: `AndroidManifest.xml`, `res/` (layouts, strings, drawables),
`assets/` (models, shaders, web UI), `apktool.yml`, plus `original/` and
`unknown/` apktool metadata. No smali/dex code is included in this dump —
resources and assets only.

> Security note: the Google API key embedded in
> `res/values/strings.xml` (`google_api_key`) was replaced with the
> placeholder `YOUR_GOOGLE_API_KEY_HERE` before upload. Put your own key
> back locally if you rebuild the app — never commit a real key.
